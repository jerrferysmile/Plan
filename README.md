前途 QIANTU v1.0 — 本地使用说明

打开方式
  1. 双击「前途.html」即可使用（推荐 Edge 或 Chrome）。
  2. 也可以双击根目录的「打开前途.bat」。
  3. 请用浏览器直接打开；不要用聊天窗口或文件管理器的「预览」打开（预览环境不执行脚本，页面会像不能操作）。

数据与备份
  1. 所有数据只存在这台电脑的浏览器里（localStorage），不上传、不联网。
  2. 备份：应用内「设置与备份」→ 导出 JSON 备份。
  3. 换电脑 / 换浏览器：在新环境打开此文件 → 设置 → 导入备份。
  4. 清理浏览器数据或更换浏览器会导致本地记录丢失，请保留 JSON 备份。

演示模式
  在地址栏 URL 末尾加 ?demo=1（例如 .../前途.html?demo=1），可预览完整效果，不会保存数据。

注意
  单文件版与文件夹版共用同一份浏览器数据（同一 file:// 来源），可以放心切换。
  旧版（原名「校准」）导出的 JSON 备份同样可以导入，数据会自动迁移。
